# PMU-B MeetingCard

ระบบบันทึกการประชุม ผู้เข้าร่วม ผู้ติดต่อ นามบัตร และงานติดตาม สำหรับงานความร่วมมือระหว่างประเทศ
ทำงานเป็นไฟล์ HTML ไฟล์เดียว ไม่มีเซิร์ฟเวอร์ ไม่มีขั้นตอน build เปิดจากเบราว์เซอร์ได้ทันที

A single-file, bilingual (ไทย/English) workspace for meeting records, participants, contacts,
business-card scanning and follow-up tracking. No server, no build step, no dependencies to install.

---

## ความสามารถ / What it does

- **บันทึกการประชุม** พร้อมวาระ ผู้เข้าร่วม สถานที่ ประเทศ/เครือข่ายความร่วมมือ และภูมิภาค
- **สแกนนามบัตรด้วยกล้อง** วางนามบัตรในกรอบ ระบบลั่นชัตเตอร์เองเมื่อภาพนิ่งและชัด แล้วอ่านชื่อ ตำแหน่ง หน่วยงาน เบอร์โทร อีเมล ที่อยู่ ให้ตรวจแก้ก่อนบันทึกเป็นผู้ติดต่อ
- **ถ่ายต่อเนื่อง** สแกนนามบัตรทีละกองได้ ระบบอ่านข้อมูลใบก่อนหน้าไปพร้อมกันเบื้องหลัง
- **งานติดตาม** พร้อมกำหนดส่ง การเตือนล่วงหน้า และการแจ้งเตือนบนหน้าแดชบอร์ด
- **ไทม์ไลน์** ดูประวัติทั้งเส้นได้จากหน้าผู้ติดต่อหรือหน้าการประชุม
- **ค้นหารวม** (Ctrl/Cmd-K) ตัวกรอง แท็ก ไฟล์แนบ
- **ส่งออก Excel** รายโมดูลหรือทั้งหมด และสำรอง/กู้คืนเป็น JSON
- **สองภาษา** สลับ ไทย/English ได้ทุกป้าย ทุกสถานะ ทุกข้อความแจ้งเตือน

## นำขึ้น GitHub Pages / Deploy

1. สร้าง repository ใหม่บน GitHub (แนะนำให้ตั้งเป็น **Private** หากไม่ต้องการให้คนอื่นเปิดหน้าเว็บนี้ได้)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น branch `main`
3. ไปที่ **Settings → Pages** เลือก **Source: GitHub Actions**
4. เมื่อ workflow ทำงานเสร็จ จะได้ URL รูปแบบ `https://<username>.github.io/<repo>/`

> **กล้องต้องใช้ HTTPS** — GitHub Pages เป็น HTTPS อยู่แล้ว จึงใช้การสแกนนามบัตรได้
> แต่ถ้าเปิดไฟล์ `index.html` จากเครื่องตรง ๆ (`file://`) กล้องจะไม่ทำงาน ระบบจะสลับไปให้เลือกรูปจากไฟล์แทน
> หากต้องการทดสอบบนเครื่อง ให้รัน `python3 -m http.server` แล้วเปิด `http://localhost:8000`

**เปิดเป็นแอปบนมือถือ** — เปิดหน้าเว็บบนมือถือ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" จะได้ไอคอนและเปิดแบบเต็มจอ สะดวกตอนสแกนนามบัตรในงานประชุม

## ข้อมูลถูกเก็บไว้ที่ไหน / Where the data lives

ระบบเลือกที่เก็บให้อัตโนมัติตามที่ที่เปิดใช้งาน และแสดงไว้ที่หน้า **ตั้งค่า → ข้อมูลของคุณ**

| ที่เปิดใช้งาน | ที่เก็บข้อมูล | อยู่ได้นานแค่ไหน |
|---|---|---|
| ในแอป Claude | พื้นที่บัญชีของ Claude | ผูกกับบัญชี เห็นเหมือนกันทุกอุปกรณ์ |
| GitHub Pages / เว็บทั่วไป | IndexedDB ของเบราว์เซอร์ | อยู่ถาวรจนกว่าจะล้างข้อมูลเบราว์เซอร์ |
| เบราว์เซอร์เก่าที่ไม่มี IndexedDB | localStorage | อยู่ถาวร แต่จุได้น้อย |
| โหมดส่วนตัว/ปิดกั้นทุกอย่าง | หน่วยความจำชั่วคราว | หายเมื่อปิดหน้า (ระบบจะขึ้นเตือน) |

หน้า **ตั้งค่า → ข้อมูลของคุณ** จะแสดงพื้นที่ที่ใช้ไปเทียบกับโควตาที่เบราว์เซอร์ให้
และมีปุ่ม **ขอให้เก็บแบบถาวร** ซึ่งเรียก `navigator.storage.persist()` เพื่อบอกเบราว์เซอร์ว่าข้อมูลชุดนี้ไม่ใช่แคชที่ลบทิ้งได้
เบราว์เซอร์มักอนุญาตให้เมื่อเว็บถูกใช้งานบ่อยหรือถูกติดตั้งเป็นแอปบนหน้าจอโฮมแล้ว

**ข้อควรทราบที่สำคัญที่สุด:** IndexedDB แยกตามเบราว์เซอร์และตามอุปกรณ์
ข้อมูลที่กรอกบนมือถือจะ **ไม่** ปรากฏบนคอมพิวเตอร์โดยอัตโนมัติ หากต้องการใช้ข้ามอุปกรณ์ ให้ตั้งค่าการซิงก์ด้านล่าง
และการล้างข้อมูลเบราว์เซอร์ (clear site data) จะลบข้อมูลนี้ไปด้วย จึงควรกดสำรองเป็นไฟล์ JSON ไว้เป็นระยะ

## ซิงก์ข้ามอุปกรณ์ / Sync across devices

ใช้ **secret gist** ของ GitHub เป็นที่พักข้อมูลกลาง เป็นการซิงก์แบบกดเอง ไม่ใช่อัตโนมัติ
เพราะการซิงก์สองทางอัตโนมัติต้องตัดสินว่าฝั่งไหนชนะเมื่อแก้พร้อมกัน และการเดาแทนผู้ใช้คือวิธีที่ข้อมูลหาย

1. สร้าง **fine-grained personal access token** ที่ https://github.com/settings/tokens
   ให้สิทธิ์เฉพาะ **Gists: Read and write** เท่านั้น ไม่ต้องให้สิทธิ์ repo
2. กรอก token ที่หน้า **ตั้งค่า → คีย์และการเชื่อมต่อ** แล้วกดบันทึก
3. กด **อัปโหลดขึ้น Gist** จากเครื่องที่ข้อมูลใหม่กว่า ระบบจะสร้าง secret gist ให้เองและแสดง Gist ID
4. บนอีกเครื่อง กรอก token เดิมและ **Gist ID** เดียวกัน แล้วกด **ดึงข้อมูลลงมา**

การดึงลงจะ **แทนที่** ข้อมูลในเครื่องนั้นทั้งหมด ระบบจะถามยืนยันก่อนเสมอ

> secret gist ไม่ปรากฏในการค้นหาและไม่แสดงในโปรไฟล์ แต่ **ไม่ได้เข้ารหัส** — ใครที่รู้ URL ก็เปิดดูได้
> หากข้อมูลการประชุมมีความอ่อนไหว ให้ใช้การสำรองเป็นไฟล์ JSON แล้วส่งผ่านช่องทางของหน่วยงานแทน

## การอ่านนามบัตรอัตโนมัติ / Card reading

การอ่านข้อมูลจากรูปนามบัตรใช้ Claude API

- **ในแอป Claude** ใช้งานได้ทันที ไม่ต้องตั้งค่าอะไร
- **บน GitHub Pages** ต้องกรอก **Anthropic API key** ของท่านเองที่หน้าตั้งค่า สร้างได้ที่ https://console.anthropic.com

คีย์ถูกเก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น **ไม่ถูกรวมในไฟล์สำรองและไม่ถูกส่งขึ้น gist**
และไม่มีอยู่ในไฟล์ที่อัปโหลดขึ้น GitHub

⚠️ **ข้อควรระวัง** เมื่อเรียก API จากเบราว์เซอร์โดยตรง คีย์จะอยู่ในเครื่องผู้ใช้
ใครที่เปิดเบราว์เซอร์เครื่องนั้นได้ก็ใช้คีย์นั้นได้ ควรตั้ง **spend limit** ให้คีย์ และเปลี่ยนคีย์ทันทีหากสงสัยว่ารั่ว
หากต้องการความปลอดภัยสูงกว่านี้ ให้ทำ proxy ฝั่งเซิร์ฟเวอร์ถือคีย์แทน แล้วชี้ปลายทางไปที่ proxy

หากปิดสวิตช์ "อ่านนามบัตรอัตโนมัติ" ในหน้าตั้งค่า รูปนามบัตรจะไม่ถูกส่งออกจากเครื่องจนกว่าจะกดปุ่มอ่านเอง

## ความเป็นส่วนตัวและความปลอดภัย / Privacy and security

ระบบนี้ออกแบบให้ตรงไปตรงมาเรื่องขอบเขตการป้องกัน

- **รหัสรับรองหน้าเข้าสู่ระบบเป็นการล็อกหน้าจอ ไม่ใช่การเข้ารหัสข้อมูล** รหัสถูกกำหนดไว้ในไฟล์ (เก็บเป็นค่าแฮช PBKDF2 ไม่ใช่ตัวอักษรตรง ๆ) ใครที่เข้าถึงไฟล์หรือเบราว์เซอร์ได้ ย่อมเปิดข้อมูลใน IndexedDB ได้โดยไม่ต้องผ่านหน้านี้
- ถ้าไม่ต้องการให้คนอื่นเปิดหน้าเว็บนี้ได้เลย **ให้ตั้ง repository เป็น Private** หรือใช้ GitHub Pages แบบจำกัดสิทธิ์ตามแผนที่องค์กรใช้อยู่
- หน้าเว็บตั้ง `noindex, nofollow` ไว้ เพื่อไม่ให้ search engine เก็บดัชนี หากต้องการให้ค้นเจอ ให้ลบ meta บรรทัดนั้นออก
- ระบบไม่มี analytics ไม่มี tracker ไม่มีการเรียกออกนอกเครื่อง ยกเว้นสามอย่าง: ฟอนต์จาก Google Fonts, ไลบรารี SheetJS จาก cdnjs (ใช้ตอนส่งออก Excel), และการเรียก Claude API เฉพาะเมื่อสั่งอ่านนามบัตร
- ข้อมูลส่วนบุคคลที่บันทึกไว้อยู่ภายใต้ พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ควรเก็บเท่าที่จำเป็นและลบเมื่อหมดความจำเป็น

## โครงสร้างไฟล์ / Files

```
index.html                      แอปทั้งหมดอยู่ในไฟล์นี้ไฟล์เดียว (HTML + CSS + JS)
README.md                       ไฟล์นี้
.gitignore                      กันไฟล์สำรองข้อมูลและไฟล์คีย์ไม่ให้ถูก commit โดยพลาด
manifest.webmanifest            ทำให้ติดตั้งเป็นแอปบนมือถือได้
icon-192.png / icon-512.png     ไอคอนแอป
.nojekyll                       บอก GitHub Pages ไม่ต้องประมวลผลด้วย Jekyll
.github/workflows/pages.yml     deploy อัตโนมัติเมื่อ push ขึ้น main
LICENSE                         MIT
```

ไม่มี `package.json` ไม่มี `node_modules` ไม่ต้อง build — แก้ `index.html` แล้ว push ได้เลย

## รหัสรับรองเริ่มต้น / Default access code

`global` — เปลี่ยนได้โดยแก้ค่าคงที่ `ACCESS` ใน `index.html` (เก็บเป็นค่าแฮช PBKDF2-SHA256 150,000 รอบ พร้อม salt คงที่)
วิธีคำนวณค่าใหม่มีอธิบายไว้ในคอมเมนต์เหนือค่าคงที่นั้น
